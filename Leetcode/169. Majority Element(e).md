### Python — Boyer-Moore voting (O(n) time, O(1) space)

The majority element (> n/2 occurrences) outnumbers everything else combined, so if
you pair off each "opposing" vote against it, it can never be fully cancelled — the
survivor is the answer.

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        count = 0
        candidate = None
        for num in nums:
            if count == 0:                 # candidate fully cancelled → pick a new one
                candidate = num
            count += 1 if num == candidate else -1   # same vote +1, opposing vote -1
        return candidate
```

- Same vote +1, opposing vote −1; when `count` hits 0, adopt the next element.
- A local run of another value can briefly steal the candidate, but the **global**
  majority always wins out because it has > n/2 votes.
- Assumes a majority exists (LC 169 guarantees it). If not guaranteed, do a **second
  pass** to verify `nums.count(candidate) > n//2`.

1. time complexity: nlogn, space complexity: 1
```c++
// Runtime: 20 ms, faster than 78.35% of C++ online submissions for Majority Element.
// Memory Usage: 19.7 MB, less than 66.30% of C++ online submissions for Majority Element.
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int l = 0, maxLen = 1, element = nums[0];
        for (int r = 1; r < nums.size(); r++) {
            if (nums[r] != nums[l]) {
                if (r - l > maxLen) {
                    maxLen = r - l;
                    element = nums[l];
                }
                l = r;
            }
        }
        if (nums.size() - l > maxLen) {
            maxLen = nums.size() - l;
            element = nums[l];
        }
        return element;
        
    }
};


class Solution {
public:
    int majorityElement(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        return nums[nums.size() / 2];
    }
};
```

2. Time complexity: O(N), space complexity: O(1)
```c++
// Runtime: 12 ms, faster than 98.19% of C++ online submissions for Majority Element.
// Memory Usage: 19.5 MB, less than 88.65% of C++ online submissions for Majority Element.
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int majority = nums[0], cnt = 1;
        for (int i = 1; i < nums.size(); i++) {
            if (cnt == 0) {
                majority = nums[i];
                cnt = 1;
            } else if (majority == nums[i]) {
                cnt++;
            } else {
                cnt--;
            }
        }
        return majority;
    }
};
```
