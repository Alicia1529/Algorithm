tag: trie, file system, design

1. Trie — each node is a dir or file

- `_traverse(path_list, create)`: walk path, optionally create missing dirs
- `children`: single source of truth for both dirs and files under a node
- `isFile` flag distinguishes files from directories

```python
from typing import List

class Node:
    def __init__(self, name, isFile=False, parent=None):
        self.name = name
        self.isFile = isFile
        self.parent = parent
        self.fileContent = ''
        self.children = {}               # name -> Node

    def output_files(self):
        if self.isFile:
            return [self.name]
        return sorted(self.children.keys())

class FileSystem:

    def __init__(self):
        self.root = Node('root')

    def _traverse(self, path_list, create=False):
        """Walk path. If create=True, make missing dirs. Returns target node."""
        curr = self.root
        for part in path_list:
            if part not in curr.children:
                if not create:
                    return None
                curr.children[part] = Node(part, isFile=False, parent=curr)
            curr = curr.children[part]
        return curr

    def ls(self, path: str) -> List[str]:
        if path == '/':
            return self.root.output_files()
        path_list = path.split('/')[1:]
        node = self._traverse(path_list)
        return node.output_files()

    def mkdir(self, path: str) -> None:
        path_list = path.split('/')[1:]
        self._traverse(path_list, create=True)

    def addContentToFile(self, filePath: str, content: str) -> None:
        path_list = filePath.split('/')[1:]
        curr = self._traverse(path_list, create=True)
        curr.isFile = True
        curr.fileContent += content

    def readContentFromFile(self, filePath: str) -> str:
        path_list = filePath.split('/')[1:]
        node = self._traverse(path_list)
        return node.fileContent
```

- `ls`: O(m + n log n) where m = path depth, n = number of entries in dir
- `mkdir`: O(m)
- `addContentToFile`: O(m + k) where k = content length
- `readContentFromFile`: O(m)
- Space: O(total characters stored across all files and dir names)
