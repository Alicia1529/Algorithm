# 70. Climbing Stairs

tag: dynamic programming

1. Space-optimized — O(1) space

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n == 1:
            return 1
        if n == 2:
            return 2
        dp = [1, 2]
        for i in range(2, n):
            curr = dp[0] + dp[1]
            dp[0], dp[1] = dp[1], curr
        return dp[1]
```

- Time: O(n), Space: O(1)
- Same structure as Fibonacci: `dp[i] = dp[i-1] + dp[i-2]`
- Base cases: n=1 → 1 way, n=2 → 2 ways (1+1 or 2)

## C++

```c++
class Solution {
public:
    int climbStairs(int n) {
        if (n == 1) return 1;
        if (n == 2) return 2;
        int dp[n];
        dp[0] = 1;
        dp[1] = 2;
        for (int i = 2; i < n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n - 1];
    }
};
```
