## Python — HashMap + dynamic array + swap-with-last

**Key idea:**
- A **hashmap** `val -> index` gives O(1) `insert`/`remove`/membership.
- But a dict can't be indexed for a uniform random pick, so pair it with a
  **dynamic array** of the values → `getRandom` is `random.choice(list)`, O(1).
- **O(1) remove:** popping an arbitrary list index is O(n) (it shifts). Instead,
  **swap the element to delete with the last element**, then `pop()` the end and
  fix the moved element's index in the map. Order never matters (we only pick
  randomly), so overwriting a hole with the tail is harmless.

```python
from random import choice

class RandomizedSet:
    def __init__(self):
        self.dict = dict()   # val -> index in self.list
        self.list = []       # values, for O(1) random access

    def insert(self, val: int) -> bool:
        if val in self.dict:
            return False
        self.dict[val] = len(self.list)
        self.list.append(val)
        return True

    def remove(self, val: int) -> bool:
        if val not in self.dict:
            return False
        last, idx = self.list[-1], self.dict[val]   # move last into the deleted slot
        self.list[idx] = last
        self.dict[last] = idx
        self.list.pop()                             # drop the duplicated tail
        del self.dict[val]
        return True

    def getRandom(self) -> int:
        return choice(self.list)
```

> Edge case handled for free: when `val` *is* the last element, the swap is a
> no-op (`list[idx]=val`, `dict[val]=idx`), then `pop()` + `del` remove it cleanly.

**Complexity:** `insert` / `remove` / `getRandom` all **O(1) average**, **O(n)** space.
