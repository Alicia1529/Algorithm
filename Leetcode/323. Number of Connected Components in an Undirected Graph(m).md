# 323. Number of Connected Components in an Undirected Graph

## Problem
Given `n` nodes labeled from `0` to `n - 1` and a list of undirected edges, return the number of connected components in the graph.

## Approach
This problem can be solved in two common ways:

- **Union-Find**: union each connected edge and count distinct root components.
- **DFS**: build an adjacency list and traverse each component.

---

## Union-Find Solution
This uses an array of parents and a component count tracked in `self.size`.

```python
from collections import defaultdict, deque

class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        self.size = n
        parents = [i for i in range(n)]

        def union(a, b):
            root_a = find(a)
            root_b = find(b)
            if root_a == root_b:
                return
            parents[root_a] = root_b
            self.size -= 1

        def find(a):
            if parents[a] != a:
                parents[a] = find(parents[a])
            return parents[a]

        for a, b in edges:
            union(a, b)
        return self.size
```

### Notes
- Time: `O(m * α(n))` ≈ `O(m)` where `m` is the number of edges
- Space: `O(n)`
- Best when input is edges and you only need component count

---

## DFS Solution
This builds an adjacency list and visits each node exactly once.

```python
from collections import defaultdict

class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        ans = 0
        outdegree = defaultdict(set)
        visited = set()

        for a, b in edges:
            outdegree[a].add(b)
            outdegree[b].add(a)

        def dfs(i):
            if i in visited:
                return
            visited.add(i)
            for nb in outdegree[i]:
                dfs(nb)

        for i in range(n):
            if i not in visited:
                ans += 1
                dfs(i)
        return ans
```

### Notes
- Time: `O(n + m)`
- Space: `O(n + m)` for adjacency list + recursion stack
- Good when you want to explore graph traversal as well as connectivity

---

## Comparison
- Use **Union-Find** when the input is an edge list and you only need the count of connected components.
- Use **DFS** when the graph is already represented as adjacency lists or when you need to traverse the component structure.
- Both are valid and efficient for this LeetCode problem.
