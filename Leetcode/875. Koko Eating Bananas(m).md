**Binary search on the answer** (Shape 3). Can't compute the best speed directly, so
guess a speed and check feasibility; feasibility is monotonic (faster speed → still
finishes), so it flips F→T once. Find the first True with Template A.

- Range: `[1, max(piles)]` — speed 1 minimum; `max(piles)` is the fastest that ever
  helps (every pile takes exactly 1 hour, total = len(piles)).
- `feasible(k)` = total hours `sum(ceil(p/k)) <= h`.
- Same skeleton as Split Array Largest Sum (410) and Capacity to Ship (1011) — only
  `feasible()` and the range change.

### Python

```python
class Solution:
    def minEatingSpeed(self, piles: List[int], h: int) -> int:
        def canFinish(k):                      # O(N)
            return sum((p + k - 1) // k for p in piles) <= h   # integer ceil

        lo, hi = 1, max(piles)
        while lo < hi:                         # Template A
            mid = (lo + hi) // 2
            if canFinish(mid):
                hi = mid                       # mid works → maybe smaller works too
            else:
                lo = mid + 1                   # mid too slow → need faster
        return lo                              # smallest feasible speed
```

- `(p + k - 1) // k` is the integer-safe ceiling (avoids float rounding for large
  piles). `math.ceil(p / k)` also works but uses float division.
- O(N · log(max(piles))) time, O(1) space.
