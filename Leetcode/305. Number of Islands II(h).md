1. Naive — re-run DFS after each position added

- After each update, count all islands from scratch
- Time: O(K × M × N), Space: O(M × N)

```python
class Solution:
    def numIslands2(self, m: int, n: int, positions: List[List[int]]) -> List[int]:
        ans = []
        grid = [[0] * n for _ in range(m)]

        def dfs(i, j, visited):
            if i < 0 or i >= m or j < 0 or j >= n:
                return
            if grid[i][j] == 0 or visited[i][j]:
                return
            visited[i][j] = True
            for x, y in [[1, 0], [-1, 0], [0, 1], [0, -1]]:
                dfs(i + x, j + y, visited)

        for x, y in positions:
            visited = [[False] * n for _ in range(m)]
            count = 0
            grid[x][y] = 1
            for i in range(m):
                for j in range(n):
                    if grid[i][j] == 1 and not visited[i][j]:
                        count += 1
                        dfs(i, j, visited)
            ans.append(count)
        return ans
```

2. Union-Find — TODO: revisit

- Each new land cell starts as its own island (count += 1)
- Union with each existing land neighbor — if different roots, merge (count -= 1)
- `find` uses path compression (halving); `union` uses rank
- Duplicate positions handled: skip if already in parent

```python
class Solution:
    def numIslands2(self, m: int, n: int, positions: List[List[int]]) -> List[int]:
        parent = dict()
        rank = dict()
        count = [0]
        ans = []

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]  # path compression (halving)
                x = parent[x]
            return x

        def union(a, b):
            ra, rb = find(a), find(b)
            if ra == rb:
                return
            if rank[ra] < rank[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            if rank[ra] == rank[rb]:
                rank[ra] += 1
            count[0] -= 1

        for x, y in positions:
            if (x, y) in parent:
                ans.append(count[0])
                continue
            parent[(x, y)] = (x, y)
            rank[(x, y)] = 0
            count[0] += 1
            for dx, dy in [[1, 0], [-1, 0], [0, 1], [0, -1]]:
                nb = (x + dx, y + dy)
                if nb in parent:
                    union((x, y), nb)
            ans.append(count[0])
        return ans
```
- Time: O(K × α(K)) where α is inverse Ackermann (nearly O(1) per operation)
- Space: O(K) for parent and rank dicts (K = number of positions)


3. User solution — 2D grid parent array

- Your version stores `parent` and `rank` as 2D grids and uses `(i,j)` tuple roots.
- It initializes each land cell lazily and merges only existing neighbors.

```python
class Solution:

    def numIslands2(self, m: int, n: int, positions: List[List[int]]) -> List[int]:
        graph = [[0] * n for _ in range(m)]
        parent = []
        rank = [[0] * n for _ in range(m)]
        ans = []
        self.num_islands = 0
        for i in range(m):
            row = []
            for j in range(n):
                row.append((i, j))
            parent.append(row)

        def union(i, j, ix, jy):
            ri, rj = find(i, j)
            rix, rjy = find(ix, jy)
            if (ri, rj) == (rix, rjy):
                return
            if rank[ri][rj] < rank[rix][rjy]:
                parent[ri][rj] = (rix, rjy)
            elif rank[ri][rj] > rank[rix][rjy]:
                parent[rix][rjy] = (ri, rj)
            else:
                parent[rix][rjy] = (ri, rj)
                rank[ri][rj] += 1
            self.num_islands -= 1

        def find(i, j):
            if parent[i][j] != (i, j):
                parent[i][j] = find(*parent[i][j])
            return parent[i][j]

        DIRECTIONS = [[-1, 0], [1, 0], [0, 1], [0, -1]]
        for i, j in positions:
            if graph[i][j] == 1:
                ans.append(self.num_islands)
                continue
            graph[i][j] = 1
            self.num_islands += 1

            for x, y in DIRECTIONS:
                ix, jy = i + x, j + y
                if 0 <= ix and ix < m and 0 <= jy and jy < n and graph[ix][jy] == 1:
                    union(i, j, ix, jy)
            ans.append(self.num_islands)
        return ans
```

- This is a valid Union-Find style solution. It is correct, but a flat index version is easier to read and a bit simpler.

- Time: O(m * n + K * α(mn)) where `m*n` is grid initialization cost and `K` is number of positions. Each `find`/`union` is amortized O(α(mn)).
- Space: O(m * n + K) because `graph`, `parent`, and `rank` are full `m x n` grids and `ans` stores K results.
