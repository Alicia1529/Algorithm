**Key insight:** the best seat is always in the widest gap of empty seats — but the
value of a gap depends on whether it's *bounded on both sides* or sits at an *edge*.

- **Middle gap** (people on both sides): you're squeezed → sit dead center →
  `gap // 2`.
- **Edge gap** (only one side has a person): hug the wall, nothing limits you →
  full length.
- Distance-to-nearest only depends on the two people flanking you, so the center of
  each gap is provably optimal → no need to check every seat. Scan the gaps once,
  take the max. O(n) time, O(1) space.

> "Squeezed in the middle → take half; backed against a wall → take it all."

### Python

```python
class Solution:
    def maxDistToClosest(self, seats: List[int]) -> int:
        n = len(seats)
        last_seat = -1                     # index of the previous occupied seat
        max_distance = 0
        for i in range(n):
            if seats[i] == 1:
                if last_seat == -1:
                    max_distance = i                         # left edge: sit at 0, full length
                else:
                    max_distance = max(max_distance, (i - last_seat) // 2)  # middle: half
                last_seat = i
        max_distance = max(max_distance, n - 1 - last_seat)  # right edge: sit at end, full length
        return max_distance
```

- Left edge distance is `i` (the leading run of empty seats), right edge is
  `n - 1 - last_seat` (the trailing run) — both taken in full, no `// 2`.
- Middle gaps use `(i - last_seat) // 2` because you're bounded on both sides.

### Contrast — not binary search

Sounds like "maximize the minimum distance" (→ binary search on the answer, e.g.
**1552. Magnetic Force Between Two Balls**), but here the people are *fixed* and you
place just one person, so a single gap scan is optimal. Recognizing which case you're
in is the meta-skill: *you choose positions* → binary search; *positions are given,
place one* → gap scan.
