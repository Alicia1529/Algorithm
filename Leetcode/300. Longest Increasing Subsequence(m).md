# 300. Longest Increasing Subsequence

tag: dynamic programming, binary search

## Python

1. Bottom-up DP — O(n²)

```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        seq = [1] * n
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] < nums[j]:
                    seq[j] = max(seq[i] + 1, seq[j])
        return max(seq)
```

- Time: O(n²), Space: O(n)
- `seq[i]` = LIS length ending at index i
- For each i, push its result forward to all j > i where nums[j] > nums[i]

## C++

### Approach 1: Dynamic Programming — O(n²)

```c++
// Runtime: 476 ms, faster than 8.76% of C++ online submissions for Longest Increasing Subsequence.
// Memory Usage: 10.6 MB, less than 13.32% of C++ online submissions for Longest Increasing Subsequence.
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n, 1);
        int ans = 1;
        
        for (int i = 0; i < nums.size(); i++) {
            for (int j = i - 1; j >= 0; j--) {
                if (nums[j] < nums[i]) {
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
            ans = max(ans, dp[i]);
        }
        return ans;
    }
};
```

### Approach 2: Binary Search — O(n log n)

```c++
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n=nums.size();
        vector<int> dp(n+1,INT_MAX);
        dp[0] = INT_MIN;
        for(int i=0; i<n; i++) {
            int idx= upper_bound(dp.begin(), dp.end(),nums[i]) - dp.begin();
            if(nums[i] > dp[idx-1] && dp[idx] > nums[i])
                dp[idx]=nums[i];
        }
        for(int i=n; i>0; i--) {
            if (dp[i] != INT_MAX)
                return i;
        }
        return 0;
    }
};
```
