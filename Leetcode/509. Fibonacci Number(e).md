tag: dynamic programming, recursion, memoization

1. Recursion (naive) — O(2^n) time

```python
class Solution:
    def fib(self, n: int) -> int:
        if n == 0: return 0
        if n == 1: return 1
        return self.fib(n - 1) + self.fib(n - 2)
```

- Time: O(2^n) — recomputes same subproblems exponentially
- Space: O(n) recursion stack

2. Top-down memoization

```python
class Solution:
    def __init__(self):
        self.memory = {0: 0, 1: 1}

    def fib(self, n: int) -> int:
        if n in self.memory:
            return self.memory[n]
        self.memory[n] = self.fib(n - 1) + self.fib(n - 2)
        return self.memory[n]
```

- Time: O(n), Space: O(n)

3. Bottom-up tabulation

```python
class Solution:
    def fib(self, n: int) -> int:
        if n <= 1: return n
        dp = [0] * (n + 1)
        dp[1] = 1
        for i in range(2, n + 1):
            dp[i] = dp[i-1] + dp[i-2]
        return dp[n]
```

- Time: O(n), Space: O(n)

4. Space-optimized — O(1) space

```python
class Solution:
    def fib(self, n: int) -> int:
        if n <= 1: return n
        a, b = 0, 1
        for _ in range(2, n + 1):
            a, b = b, a + b
        return b
```

- Time: O(n), Space: O(1)
- dp[i] only depends on dp[i-1] and dp[i-2] → two variables suffice
