**Bitmask (state-compression) DP.**

- **Key insight — compress the smaller dimension.** People `n ≤ 10`, hats `≤ 40`.
  Recording "which hats are used" needs `2^40` (explodes); recording "which people
  already have a hat" needs only `2^10 = 1024`. So **iterate over hats, and use an
  n-bit bitmask over people.**
- **`mask`** = n-bit number, bit `i` set ⇒ person `i` already has a hat. `2^n`
  because it's the number of *subsets* of people, not `n`. `full = (1<<n)-1` = everyone assigned.
- **State** `dp(hat, mask)` = ways to finish assigning from hat `hat` onward so that
  everyone not yet in `mask` gets a hat.
- **Transition** at each hat: either give it to nobody `dp(hat+1, mask)`, or give it
  to some person `p` who wants it and is still free `dp(hat+1, mask | 1<<p)`.
- `hat_to_people` has **41 entries** (indices 0..40) so the index equals the 1-based
  hat number; index 0 is unused padding.

### Python

```python
from functools import lru_cache

class Solution:
    def numberWays(self, hats: List[List[int]]) -> int:
        MOD = 10**9 + 7
        n = len(hats)                      # number of people
        full = (1 << n) - 1                # everyone has a hat

        # flip the data: hat -> people who are willing to wear it
        hat_to_people = [[] for _ in range(41)]   # indices 0..40; hats are 1..40
        for person, hat_list in enumerate(hats):
            for h in hat_list:
                hat_to_people[h].append(person)

        @lru_cache(maxsize=None)
        def dp(hat, mask):
            if mask == full:               # everyone assigned → 1 complete way
                return 1
            if hat > 40:                   # ran out of hats, someone still bare → fail
                return 0
            ways = dp(hat + 1, mask)       # choice 1: give this hat to nobody
            for p in hat_to_people[hat]:   # choice 2: give it to a willing, free person
                if not (mask & (1 << p)):
                    ways += dp(hat + 1, mask | (1 << p))
            return ways % MOD

        return dp(1, 0)                    # start at hat 1, nobody assigned
```

- Complexity: states `40 × 2^n ≈ 40 × 1024 ≈ 40k`, each scans ≤ n people →
  ~400k ops. Compressing hats instead would be `2^40` (~1 trillion) → the flip is
  the whole point.
- Recognition cue: "assign each element, no conflicts" + one dimension `≤ ~20` →
  bitmask DP over the small dimension. Same family: 698 · 847 · 1349.
