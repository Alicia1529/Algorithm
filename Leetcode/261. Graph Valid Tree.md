# 261. Graph Valid Tree

Problem summary
- Given `n` nodes labeled `0` to `n-1` and an edge list for an undirected graph, determine if the graph is a valid tree.

Key facts
- A graph is a tree iff it's connected and has exactly `n - 1` edges.

Why those checks are sufficient
- If a graph is connected and has `n-1` edges, it cannot contain a cycle (otherwise you could remove an edge and remain connected, giving < n-1 edges), so it must be a tree.

Python — iterative DFS that checks cycles (single-pass)
```python
from typing import List
from collections import defaultdict

class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        if n == 0:
            return True
        # build adjacency
        graph = defaultdict(set)
        for a, b in edges:
            graph[a].add(b)
            graph[b].add(a)

        seen = set()
        stack = [(0, -1)]  # (node, parent)
        while stack:
            node, parent = stack.pop()
            if node in seen:
                continue
            seen.add(node)
            for nei in graph[node]:
                if nei == parent:
                    continue
                if nei in seen:
                    return False  # found a cycle
                stack.append((nei, node))

        return len(seen) == n
```

Python — recursive DFS with parent tracking
```python
from typing import List
from collections import defaultdict

class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        if n == 0:
            return True
        graph = defaultdict(set)
        for a, b in edges:
            graph[a].add(b)
            graph[b].add(a)

        visited = set()

        def dfs(node: int, parent: int) -> bool:
            if node in visited:
                return False
            visited.add(node)
            for neighbor in graph[node]:
                if neighbor == parent:
                    continue
                if not dfs(neighbor, node):
                    return False
            return True

        return dfs(0, -1) and len(visited) == n
```

Analysis of the recursive DFS approach
- It detects cycles by using `parent` to ignore the edge back to the immediate predecessor.
- If a neighbor is already visited and is not the parent, we found a cycle.
- `visited` tracks reachability; after DFS finishes, `len(visited) == n` confirms the graph is connected.
- This version is clean and direct, but it can use recursion depth equal to tree height. For large graphs, an iterative version may be safer.

Python — connectivity-only iterative DFS plus `n-1` edge check (cheap and common)
```python
from typing import List
from collections import defaultdict

class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        if len(edges) != n - 1:
            return False
        graph = defaultdict(set)
        for a, b in edges:
            graph[a].add(b)
            graph[b].add(a)
        seen = {0}
        stack = [0]
        while stack:
            node = stack.pop()
            for child in graph[node]:
                if child in seen:
                    continue
                seen.add(child)
                stack.append(child)
        return len(seen) == n
```

Python — Union-Find (disjoint set)
```python
class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        if n == 0:
            return True
        if len(edges) != n - 1:
            return False

        parent = list(range(n))
        rank = [0] * n
        components = n

        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return x

        def union(a, b):
            nonlocal components
            ra, rb = find(a), find(b)
            if ra == rb:
                return False
            if rank[ra] < rank[rb]:
                parent[ra] = rb
            elif rank[rb] < rank[ra]:
                parent[rb] = ra
            else:
                parent[rb] = ra
                rank[ra] += 1
            components -= 1
            return True

        for a, b in edges:
            if not union(a, b):
                return False
        return components == 1
```

Java — Union-Find
```java
class UnionFind {
    int[] parent, rank;
    UnionFind(int n) {
        parent = new int[n]; rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    boolean union(int a, int b) {
        int pa = find(a), pb = find(b);
        if (pa == pb) return false;
        if (rank[pa] < rank[pb]) parent[pa] = pb;
        else if (rank[pb] < rank[pa]) parent[pb] = pa;
        else { parent[pb] = pa; rank[pa]++; }
        return true;
    }
}

public class Solution {
    public boolean validTree(int n, int[][] edges) {
        if (edges.length != n - 1) return false;
        UnionFind uf = new UnionFind(n);
        for (int[] e : edges) if (!uf.union(e[0], e[1])) return false;
        return true;
    }
}
```

Complexity
- Time: O(n + m) for DFS/BFS; Union-Find roughly O(m * α(n)).
- Space: O(n + m) for adjacency; O(n) for DSU arrays.

Notes
- Iterative DFS that only checks connectivity must be combined with `len(edges) == n-1` to guarantee acyclicity.
- Single-pass DFS/Union-Find can both detect cycles directly without the separate edges check.

Examples
- `n=5`, `edges=[[0,1],[0,2],[0,3],[1,4]]` → True
- `n=5`, `edges=[[0,1],[1,2],[2,3],[1,3],[1,4]]` → False (cycle)
