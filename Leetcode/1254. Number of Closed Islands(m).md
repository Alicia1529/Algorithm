tag: dfs, flood fill, grid

1. Flood-fill from borders, then count remaining islands

- DFS from all border 0s to mark them as unreachable (not closed)
- Count remaining interior 0s — each is a closed island

```python
from typing import List

class Solution:
    def closedIsland(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        def dfs(i, j):
            if i < 0 or i >= m or j < 0 or j >= n:
                return
            if grid[i][j] == 1:
                return
            grid[i][j] = 1
            for x, y in [[-1, 0], [1, 0], [0, 1], [0, -1]]:
                dfs(i + x, j + y)

        for i in range(n):
            dfs(0, i)
            dfs(m - 1, i)
        for i in range(m):
            dfs(i, 0)
            dfs(i, n - 1)

        ans = 0
        for i in range(1, m - 1):
            for j in range(1, n - 1):
                if grid[i][j] == 0:
                    ans += 1
                    dfs(i, j)
        return ans
```

- Time: O(m × n)
- Space: O(m × n) recursion stack worst case

1. DFS per island — check if it touches border (non-destructive)

- For each unvisited 0, DFS and ask "does this island touch the border?"
- Accumulates result across all directions before returning (no early exit)
- Uses separate `visited` array — does not modify input grid

```python
class Solution:
    def closedIsland(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        visited = [[False] * n for _ in range(m)]

        def dfs_touches_border(i, j):
            if i < 0 or i >= m or j < 0 or j >= n:
                return True
            if visited[i][j] or grid[i][j] == 1:
                return False
            visited[i][j] = True
            touches_border = False
            for x, y in [[-1, 0], [1, 0], [0, 1], [0, -1]]:
                if dfs_touches_border(i + x, j + y):
                    touches_border = True
            return touches_border

        ans = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 0 and not visited[i][j] and not dfs_touches_border(i, j):
                    ans += 1
        return ans
```

- Time: O(m × n)
- Space: O(m × n) for visited array + recursion stack

1. DFS per island with a boolean flag (destructive, no early exit)

- For each unvisited 0, DFS the whole island; flip a shared boolean to `True` if any cell steps out of bounds
- Mutates the grid in place (no separate `visited` array)
- Boolean is wrapped in a list so the recursion can write to it across calls

```python
class Solution:
    def closedIsland(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        ans = 0

        def dfs(i, j, touch_border):
            if i < 0 or i >= m or j < 0 or j >= n:
                touch_border[0] = True
                return
            if grid[i][j] != 0:
                return
            grid[i][j] = 1
            for x, y in [[1, 0], [-1, 0], [0, 1], [0, -1]]:
                dfs(i + x, j + y, touch_border)

        for i in range(m):
            for j in range(n):
                if grid[i][j] == 0:
                    touch_border = [False]
                    dfs(i, j, touch_border)
                    if not touch_border[0]:
                        ans += 1
        return ans
```

- Time: O(m × n)
- Space: O(m × n) recursion stack worst case
- Note: `touch_border` is a one-element list because Python closures can read but not rebind outer variables; the list lets the recursion mutate a shared value
