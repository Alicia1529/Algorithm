Given `nums` where `nums[i]` is the max jump length from index `i`, decide whether you can reach the last index.

### Python

**Greedy — forward reachability (best)** — track the farthest index reachable so far and extend it as you scan left to right. You never simulate individual jumps: if the frontier ever falls behind the current index, there is a gap you cannot cross.

```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        n = len(nums)
        max_reach = 0
        for i in range(n):
            if max_reach < i:
                return False
            max_reach = max(max_reach, i + nums[i])
        return True
```

O(n) time, O(1) space. The `max_reach < i` check must come **before** the update — otherwise a `0` at index `i` gets to extend the frontier from a square you never actually stood on.

**Greedy — backward** — shrink the target. Walking right to left, if `i` can reach the current target, `i` becomes the new target. Reachable iff the target collapses to 0.

```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        last = len(nums) - 1
        for i in range(len(nums) - 1, -1, -1):
            if i + nums[i] >= last:
                last = i
        return last == 0
```

### C++

Dynamic Programming Top-down
```c++
// Runtime: 1208 ms, faster than 5.11% of C++ online submissions for Jump Game.
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int len = nums.size();
        int canArrive[len];
        memset(canArrive, 0, sizeof(canArrive));
        canArrive[0] = 1;
        for (int i = 0; i < len; i++) {
            if (canArrive[i] == 0) continue;
            for (int j = 0; j <= nums[i] && i + j < len ; j++) {
                canArrive[i + j] = 1;
            }
        }
        return canArrive[len - 1] == 1;
    }
};
```
> O(n·max(nums)) — this is why it's slow. The greedy versions collapse the inner loop into a single `max`.

Greedy
```c++
// Runtime: 20 ms, faster than 46.36% of C++ online submissions for Jump Game.
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int lastPosition = nums.size() - 1;
        for (int i = nums.size() - 1; i >= 0; i--) {
            if (i + nums[i] >= lastPosition)
                lastPosition = i;
        }
        return lastPosition == 0;
    }
};
```
