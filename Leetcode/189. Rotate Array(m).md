**Key insight:** a right-rotation by `k` maps every element `i → (i+k) % n`. That's a
*permutation*, and permutations decompose into cycles. Two O(1)-space ways to exploit
it: (a) walk each cycle carrying the displaced value ("hot potato"), or (b) three
reversals. Rotation-as-reversal is the most foolproof under pressure.

### Python

```python
# Method 1 — brute force: rotate by 1, k times. O(n·k) time, O(1) space.
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n
        for _ in range(k):
            last = nums[-1]
            for j in range(n):
                nums[j], last = last, nums[j]

# Method 2 — extra array: place each element directly. O(n) time, O(n) space.
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n
        output = [0] * n
        for i in range(n):
            output[(i + k) % n] = nums[i]
        nums[:] = output                      # copy back in place

# Method 3 — three reversals. O(n) time, O(1) space. MOST foolproof.
# reverse all → reverse first k → reverse the rest.
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n
        def reverse(i, j):
            while i < j:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
                j -= 1
        reverse(0, n - 1)
        reverse(0, k - 1)
        reverse(k, n - 1)

# Method 4 — cyclic replacement. O(n) time, O(1) space.
# Walk each cycle; there are gcd(n,k) cycles, so COUNT placements to stop.
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n
        if k == 0:
            return
        count, start = 0, 0
        while count < n:                      # until all n elements are placed
            prev, curr = nums[start], start
            while True:
                next_idx = (curr + k) % n
                nums[next_idx], prev = prev, nums[next_idx]   # drop value, grab displaced one
                count += 1
                if next_idx == start:         # cycle closed
                    break
                curr = next_idx
            start += 1                         # next cycle's start
```

- **M1** is simplest but O(n·k). **M2** is the clearest O(n) but uses a copy.
- **M3 (reversals)** and **M4 (cyclic)** are the two O(n)/O(1) answers. M4 is more
  elegant but the "`gcd(n,k)` cycles → use a counter to know when done" is the
  easy-to-miss part; M3 sidesteps that entirely — prefer it in an interview.
