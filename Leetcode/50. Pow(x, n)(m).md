**Key insight — decrement → halve.** Brute force shrinks the exponent by 1
(`xⁿ = x · x^(n-1)`, O(n) → TLE for `n` up to 2³¹). Fast power uses
`xⁿ = (x^(n/2))²` to shrink it by *half* → O(log n). Critical: compute `x^(n/2)`
**once** and reuse it — calling it twice re-branches back to O(n). Think of `n` in
binary: it has only `log n` bits, so touch each bit once, don't count to `n`.

### Python

```python
# Fast power, recursive. O(log n) time, O(log n) stack.
# Compute half ONCE, reuse in both even and odd branches.
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n == 0: return 1
        if n < 0: return 1 / self.myPow(x, -n)      # x^(-n) = (1/x)^n
        half = self.myPow(x, n // 2)                # ← single call
        if n % 2 == 0:
            return half * half                      # xⁿ = (x^(n/2))²
        return x * half * half                      # odd: xⁿ = x · (x^(n/2))²

# Equivalent: square the base and recurse once (no separate odd/even reuse needed).
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n == 0: return 1
        if n < 0: return 1 / self.myPow(x, -n)
        if n % 2 == 0:
            return self.myPow(x * x, n // 2)         # double the base, halve the exp
        return x * self.myPow(x * x, n // 2)

# Iterative, binary exponentiation. O(log n) time, O(1) space.
# Multiply into result at each 1-bit of n; square x each step.
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n < 0:
            x, n = 1 / x, -n
        result = 1
        while n:
            if n & 1:            # current bit set → include this power
                result *= x
            x *= x               # x, x², x⁴, x⁸, ...
            n >>= 1
        return result
```

- **Trap (both are O(n)/TLE):** `return myPow(x, n//2) * myPow(x, n//2)` calls the
  same subproblem twice → branching tree → O(n). And an odd branch that recurses on
  `n - 1` (decrement) instead of `n // 2` (halve) is also O(n).
- Edge case: `n = -2³¹` overflows `-n` in fixed-width languages (cast to long first);
  in Python it's fine (arbitrary precision).

### C++

```c++
// Runtime: 0 ms, faster than 100.00% of C++ online submissions for Pow(x, n).

class Solution {
public:
    double myPow(double x, int n) {
        if (x == 0) return 0;
        if (n == 0) return 1;
        if (n == 1) return x;
        if (n == -1) return 1 / x;

        double y = myPow(x, n / 2);
        return y * y * myPow(x, n % 2);
    }
};


class Solution {
public:
    double myPow(double x, int n) {
        if (x == 0) return 0;
        if (n == 0) return 1;
        if (n == 1) return x;
        if (n == -1) return 1 / x;
        double base = 1;
        if (abs(n % 2) == 1 && n > 0) {
            base = x;
        } else if (abs(n % 2) == 1 && n < 0) {
            base = 1/x;
        }
        double ret = myPow(x, n / 2);
        // printf("n = %d, n / 2 = %d,  n % 2 = %d, ret = %f, base = %f\n", n, n / 2, n % 2, ret, base);
        return base * ret * ret;
    }
};

class Solution {
public:
    double myPow(double x, int n) {
        double res = 1;
        while (n) {
            if (n % 2) res = n > 0 ? res * x : res / x;
            x = x * x;
            n /= 2;
        }
        return res;
    }
};
```
