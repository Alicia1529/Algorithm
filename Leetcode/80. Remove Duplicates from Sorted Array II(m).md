Keep at most 2 copies of each value in a sorted array, in place. Return the new length `k`.

### Python

**1. Compare against the kept window** — the slot `k - 2` holds the earliest of the last two kept values. If `nums[i]` equals it, we already have two copies, so skip. No counter needed, and it generalizes to "at most m" by using `k - m`.

```python
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        k = 0
        for i in range(len(nums)):
            if k >= 2 and nums[i] == nums[k - 2]:
                continue
            nums[k] = nums[i]
            k += 1
        return k
```

**2. Count runs, start at index 1** — the first element is always kept, so seed `k = 1, cnt = 1` and scan from `i = 1`. This seeding assumes the array is non-empty (true on LeetCode, where `n >= 1`); the `if not nums` guard makes it safe anyway.

```python
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        if not nums:
            return 0
        k = 1
        cnt = 1
        for i in range(1, len(nums)):
            if nums[i] == nums[i - 1]:
                cnt += 1
            else:
                cnt = 1
            if cnt > 2:
                continue
            nums[k] = nums[i]
            k += 1
        return k
```

**3. Count runs, start at index 0** — same idea with the `i > 0` guard folded into the loop, so no seeding is needed and the empty array falls out naturally.

```python
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        k = 0
        cnt = 0
        for i in range(len(nums)):
            if i > 0 and nums[i] == nums[i - 1]:
                cnt += 1
            else:
                cnt = 1
            if cnt > 2:
                continue
            nums[k] = nums[i]
            k += 1
        return k
```

All three are O(n) time, O(1) space.

### C++

**1. Count runs**

```C++
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        if (nums.size() <= 2) return nums.size();
        int idx = 1;
        int cnt = 1;
        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] == nums[i - 1] && cnt > 1)
                continue;
            if (nums[i] != nums[i - 1]) {
                cnt = 1;
            } else {
                cnt++;
            }
            nums[idx++] = nums[i];
        }
        return idx;
    }
};
```

**2. Compare against the kept window**

```C++
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int len = 2;
        int n = nums.size();
        if (n <= 2) return n;
        for (int i = 2; i < n; i++) {
            if (nums[i] != nums[len - 2]) {
                nums[len] = nums[i];
                len++;
            }
        }
        return len;
    }
};
```
