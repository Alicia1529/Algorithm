## Python — Kadane's algorithm, O(n) time / O(1) space

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        cur = best = nums[0]
        for x in nums[1:]:
            cur = max(x, cur + x)   # extend the running subarray, or start fresh at x
            best = max(best, cur)   # track the best subarray seen so far
        return best
```

**Idea (Kadane):** `cur` holds the largest subarray sum that *ends at the current
element*. At each step you decide: extend the previous subarray (`cur + x`) or
drop it and start a new one at `x`. You start fresh whenever `cur` has gone
negative, since a negative prefix can only drag down whatever follows. `best`
records the maximum across all positions.

- Seeding both `cur` and `best` with `nums[0]` (instead of `0`) handles the
  all-negative case correctly — e.g. `[-3, -1, -2]` returns `-1`, not `0`.
- One pass, no extra arrays → **O(n) time, O(1) space**.

Trace on `[-2, 1, -3, 4, -1, 2, 1, -5, 4]` → answer `6` (subarray `[4, -1, 2, 1]`):

| x    | cur = max(x, cur+x) | best |
|------|---------------------|------|
| -2   | -2                  | -2   |
| 1    | 1                   | 1    |
| -3   | -2                  | 1    |
| 4    | 4                   | 4    |
| -1   | 3                   | 4    |
| 2    | 5                   | 5    |
| 1    | 6                   | **6** |
| -5   | 1                   | 6    |
| 4    | 5                   | 6    |

## Approach 2 — DP with an explicit array, O(n) time / O(n) space

Same recurrence as Kadane, but stored in a table to make the subproblem explicit.
`dp[i]` = max subarray sum **ending at index `i`** = `max(nums[i], dp[i-1] + nums[i])`.

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        dp = [0] * len(nums)
        dp[0] = nums[0]
        for i in range(1, len(nums)):
            dp[i] = max(nums[i], dp[i - 1] + nums[i])
        return max(dp)
```

Kadane is just this with the `dp` array collapsed to a single rolling variable.

## Approach 3 — Prefix sum + running minimum, O(n) time / O(1) space

The sum of `nums[i..j]` is `prefix[j] - prefix[i-1]`. To maximize it while ending
at `j`, subtract the **smallest prefix seen so far**. Track that minimum as you go.

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        best = float('-inf')
        prefix = 0
        min_prefix = 0          # smallest prefix sum before the current index
        for x in nums:
            prefix += x
            best = max(best, prefix - min_prefix)
            min_prefix = min(min_prefix, prefix)
        return best
```

Useful framing because it generalizes to problems that need actual prefix sums.

## Approach 4 — Divide and conquer, O(n log n) time

Split the array in half. The max subarray is the best of three cases:
1. entirely in the **left** half,
2. entirely in the **right** half,
3. **crossing** the midpoint — extend greedily left from mid and right from mid+1.

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        def solve(lo, hi):
            if lo == hi:
                return nums[lo]
            mid = (lo + hi) // 2

            # best subarray crossing the midpoint
            left_sum, s = float('-inf'), 0
            for i in range(mid, lo - 1, -1):
                s += nums[i]
                left_sum = max(left_sum, s)
            right_sum, s = float('-inf'), 0
            for i in range(mid + 1, hi + 1):
                s += nums[i]
                right_sum = max(right_sum, s)
            cross = left_sum + right_sum

            return max(solve(lo, mid), solve(mid + 1, hi), cross)

        return solve(0, len(nums) - 1)
```

Slower than Kadane (`O(n log n)` vs `O(n)`), but it's the classic interview
follow-up: *"can you solve it divide-and-conquer?"*

**Summary**

| Approach | Time | Space | Notes |
|---|---|---|---|
| Kadane (rolling) | O(n) | O(1) | the go-to answer |
| DP array | O(n) | O(n) | makes the recurrence explicit |
| Prefix sum + min | O(n) | O(1) | generalizes to prefix-sum problems |
| Divide & conquer | O(n log n) | O(log n) | the classic follow-up |
