tag: matrix, hash table

The word **"Sparse"** is the signal: most entries are zero, so the intended solution
**skips the zeros** rather than doing dense O(m·n·k) multiplication.

**Naive dense baseline** (correct, but ignores sparsity — state this first in an interview):

```python
class Solution:
    def multiply(self, mat1: List[List[int]], mat2: List[List[int]]) -> List[List[int]]:
        m, k = len(mat1), len(mat1[0])
        n = len(mat2[0])
        # m x k  *  k x n  =>  m x n
        output = [[0] * n for _ in range(m)]

        for i in range(m):
            for j in range(n):
                total = 0
                for l in range(k):
                    total += mat1[i][l] * mat2[l][j]
                output[i][j] = total
        return output
```

**Zero-skip (the intended answer)** — reorder loops to `i → l → j`. If `mat1[i][l] == 0`
it contributes nothing to *any* `output[i][j]`, so skip the whole inner loop:

```python
class Solution:
    def multiply(self, mat1: List[List[int]], mat2: List[List[int]]) -> List[List[int]]:
        m, k = len(mat1), len(mat1[0])
        n = len(mat2[0])
        output = [[0] * n for _ in range(m)]

        for i in range(m):
            for l in range(k):
                if mat1[i][l] == 0:        # skip: contributes nothing to any output[i][j]
                    continue
                for j in range(n):
                    if mat2[l][j] != 0:    # optional second skip
                        output[i][j] += mat1[i][l] * mat2[l][j]
        return output
```

> Why reorder? With `i → j → l`, a zero check saves one multiplication. With `i → l → j`,
> a single zero in `mat1` skips an entire row of inner work (all `n` values of `j`).

**Compressed non-zero lists** — pre-extract non-zeros so you never touch a zero. Best when
the matrices are huge and very sparse:

```python
class Solution:
    def multiply(self, mat1: List[List[int]], mat2: List[List[int]]) -> List[List[int]]:
        m, k, n = len(mat1), len(mat1[0]), len(mat2[0])
        output = [[0] * n for _ in range(m)]

        def nonzeros(mat):                 # row -> list of (col, value)
            d = {}
            for r, row in enumerate(mat):
                for c, v in enumerate(row):
                    if v:
                        d.setdefault(r, []).append((c, v))
            return d

        A, B = nonzeros(mat1), nonzeros(mat2)
        for i in A:                        # only rows of mat1 with non-zeros
            for l, a in A[i]:
                if l in B:                 # only if mat2 row l has non-zeros
                    for j, b in B[l]:
                        output[i][j] += a * b
        return output
```

**Complexity:** all three are O(m·n·k) worst case (dense input). The zero-skip and
compressed versions run proportional to the number of *non-zero* products, which is the
whole win on sparse input.
