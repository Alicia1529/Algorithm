# 15. 3Sum

## Python

1. Two pointers

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        ans = []
        nums.sort()

        def twoSum(i):
            lo, hi = i + 1, len(nums) - 1
            while lo < hi:
                three_sum = nums[i] + nums[lo] + nums[hi]
                if three_sum > 0:
                    hi -= 1
                elif three_sum < 0:
                    lo += 1
                else:
                    ans.append([nums[i], nums[lo], nums[hi]])
                    while lo < hi and nums[lo] == nums[lo + 1]:
                        lo += 1
                    while lo < hi and nums[hi] == nums[hi - 1]:
                        hi -= 1
                    lo += 1
                    hi -= 1

        for i in range(len(nums)):
            if nums[i] > 0:
                break
            if i == 0 or nums[i - 1] != nums[i]:
                twoSum(i)
        return ans
```

- Time: O(N²), Space: O(1)

1. Hash set (twoSum style)

- `complement = -nums[i] - nums[j]`: if complement is in `seen`, found a triplet
- `seen` stores values BEFORE j, so complement is always ≤ nums[j] → output is sorted

⚠️ **Easy to get wrong — duplicate skip must be inside the match block only:**

```python
# WRONG: always skipping causes [0,0,0] → [] (jumps past j=2 before seen has 0)
seen.add(nums[j])
while nums[j] == nums[j+1]: j += 1   # always runs
j += 1

# CORRECT: skip duplicates only after a triplet is found
if complement in seen:
    ans.append(...)
    while nums[j] == nums[j+1]: j += 1   # only runs on match
seen.add(nums[j])
j += 1
```

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        ans = []
        nums.sort()

        def twoSum(i):
            seen = set()
            j = i + 1
            while j < len(nums):
                complement = -nums[i] - nums[j]
                if complement in seen:
                    ans.append([nums[i], complement, nums[j]])
                    while j + 1 < len(nums) and nums[j] == nums[j+1]:
                        j += 1
                seen.add(nums[j])
                j += 1

        for i in range(len(nums)):
            if nums[i] > 0:
                break
            if i == 0 or nums[i - 1] != nums[i]:
                twoSum(i)
        return ans
```

- Time: O(N²), Space: O(N)

1. Hash set, no sort (dedup via result set)

- No sorting — instead canonicalize each triplet with `tuple(sorted(...))` and store in a
  `res` set, so duplicate triplets collapse automatically.
- `dups` skips repeated *first* elements (`nums[i]`) so we don't redo identical outer scans.
- `seen` holds values in `nums[i+1:]` already visited; if `complement` is among them, the
  triplet `(nums[i], nums[j], complement)` sums to 0.

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        res = set()
        dups = set()              # first-element values already processed
        for i in range(len(nums)):
            if nums[i] in dups:   # skip equal first elements (efficiency)
                continue
            dups.add(nums[i])
            seen = set()          # values seen in nums[i+1:] so far
            for j in range(i + 1, len(nums)):
                complement = -nums[i] - nums[j]
                if complement in seen:
                    res.add(tuple(sorted((nums[i], nums[j], complement))))
                seen.add(nums[j])
        return [list(t) for t in res]
```

- Time: O(N²), Space: O(N). Avoids the O(N log N) sort, but pays it back in hashing +
  `tuple(sorted(...))` per match — useful when the input must stay unsorted.

## C++
```C++
// *** important: how to remove duplicate
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        int size = nums.size();
        vector<vector<int>> ans;
        sort(nums.begin(), nums.end());

        for (int i = 0; i < size; i++) {
            if (i > 0 && nums[i] == nums[i - 1])
                continue;
            int front = i + 1, back = size - 1;
            while (front < back) {
                int threeSum = nums[i] + nums[front] + nums[back];
                if (threeSum > 0) {
                    back--;
                } else if (threeSum < 0) {
                    front++;
                } else {
                    ans.push_back({nums[i], nums[front], nums[back]});
                    front++;
                    while (front < back && nums[front] == nums[front - 1])
                        front++;
                }
            }
        }
        return ans;
    }
};
```
