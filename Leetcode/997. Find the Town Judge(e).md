tag: graph, in-degree, out-degree

The town judge has in-degree `n-1` (everyone else trusts them) and out-degree `0` (trusts nobody).

1. Two maps — in-degree and out-degree

- Count incoming and outgoing edges separately
- The judge is the person with `outdegree == 0` and `indegree == n - 1`
- Reads directly off the problem statement

```python
from collections import defaultdict
from typing import List

class Solution:
    def findJudge(self, n: int, trust: List[List[int]]) -> int:
        indegree = defaultdict(int)
        outdegree = defaultdict(int)

        for a, b in trust:
            outdegree[a] += 1
            indegree[b] += 1

        for i in range(1, n + 1):
            if outdegree[i] == 0 and indegree[i] == n - 1:
                return i
        return -1
```

- Time: O(E + N)
- Space: O(N)

2. Single score array

- `+1` when trusted, `-1` when trusting
- The judge ends with exactly `n - 1`: this implies both 0 out-edges and `n-1` in-edges, since max in-degree is `n-1` and any out-edge would subtract
- One pass to build, one pass to scan

```python
from typing import List

class Solution:
    def findJudge(self, n: int, trust: List[List[int]]) -> int:
        score = [0] * (n + 1)
        for a, b in trust:
            score[a] -= 1   # a trusts someone → can't be judge
            score[b] += 1   # b is trusted
        for i in range(1, n + 1):
            if score[i] == n - 1:
                return i
        return -1
```

- Time: O(E + N)
- Space: O(N)
- Edge case: `n == 1, trust == []` → returns `1` (lone person is trivially the judge, `score[1] == 0 == n - 1`)
