# 122. Best Time to Buy and Sell Stock II

tag: greedy

## Python

1. Greedy — collect every upward step

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        profit = 0
        for idx, price in enumerate(prices):
            if idx > 0 and price > prices[idx - 1]:
                profit += price - prices[idx - 1]
        return profit
```

- Time: O(n), Space: O(1)
- Add `price - prev` whenever price rises — equivalent to buying at every local min and selling at every local max

```c++
// Runtime: 12 ms, faster than 42.19% of C++ online submissions for Best Time to Buy and Sell Stock II.
// Memory Usage: 12.9 MB, less than 91.47% of C++ online submissions for Best Time to Buy and Sell Stock II.
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if (prices.size() <= 1) return 0;
        int profit = 0;
        for (int i = 1; i < prices.size(); i++) {
            if (prices[i] - prices[i - 1] > 0)
                profit += prices[i] - prices[i - 1];
        }
        return profit;
    }
};
```
