### C++
```C++
class Solution {
public:
    int strStr(string haystack, string needle) {
        if (needle.size() == 0) return 0;
        if (haystack.size() == 0 || haystack.size() < needle.size()) return -1;
        for (int i = 0; i <= haystack.size() - needle.size(); i++) {
            bool eq = true;
            for (int j = 0; j < needle.size(); j++) {
                if (haystack[i + j] != needle[j]) {
                    eq = false;
                    break;
                }
            }
            if (eq) return i;
        }
        return -1;
    }
};
```

when `haystack.size() < needle.size()`, the following codes will result in

because the for loop will never end.

### Python

Sliding window, brute force — O(n·m) time, O(1) space. No need for the C++ size guard:
`range(n - m + 1)` is empty when `m > n`, so it falls through to `return -1` safely.

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        n, m = len(haystack), len(needle)
        for window_start in range(n - m + 1):
            for i in range(m):
                if needle[i] != haystack[window_start + i]:
                    break
                if i == m - 1:           # matched all of needle
                    return window_start
        return -1
```
