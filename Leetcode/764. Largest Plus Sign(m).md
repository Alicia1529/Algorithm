# 764. Largest Plus Sign

In an `n × n` grid that is all `1`s except for the cells listed in `mines` (which
are `0`), find the order of the **largest plus sign** made entirely of `1`s.
A plus of order `k` centered at a cell has 4 arms of length `k-1` extending
up/down/left/right (plus the center), all of which must be `1`. Return the
largest order `k`, or `0` if none.

## Key insight

The order of a plus centered at `(r, c)` is the **minimum** of how many consecutive
`1`s extend from that cell in each of the 4 directions (counting the center).

So for every cell compute four directional run-lengths of `1`s, take the min →
that's the largest plus centerable there. The answer is the max over all cells.

## DP — 4 directional sweeps, O(n²)

`dp[r][c]` accumulates the min consecutive-`1` run across all four directions.
Each pass uses the classic "consecutive ones" recurrence:
`count = 0 if cell is a mine else count + 1`.

```python
class Solution:
    def orderOfLargestPlusSign(self, n: int, mines: List[List[int]]) -> int:
        mine = {(r, c) for r, c in mines}
        dp = [[0] * n for _ in range(n)]

        for r in range(n):
            count = 0                       # left -> right
            for c in range(n):
                count = 0 if (r, c) in mine else count + 1
                dp[r][c] = count
            count = 0                       # right -> left
            for c in range(n - 1, -1, -1):
                count = 0 if (r, c) in mine else count + 1
                dp[r][c] = min(dp[r][c], count)

        for c in range(n):
            count = 0                       # top -> bottom
            for r in range(n):
                count = 0 if (r, c) in mine else count + 1
                dp[r][c] = min(dp[r][c], count)
            count = 0                       # bottom -> top
            for r in range(n - 1, -1, -1):
                count = 0 if (r, c) in mine else count + 1
                dp[r][c] = min(dp[r][c], count)

        return max(max(row) for row in dp)
```

## Why it works

- After the **left→right** pass, `dp[r][c]` = number of consecutive `1`s ending at
  `(r,c)` looking left (left arm + center).
- Each later pass overwrites with `min(dp[r][c], <that direction's run>)`.
- After all 4 passes, `dp[r][c]` = smallest of the 4 arm lengths = the largest plus
  order centerable there. A mine cell resets `count` to `0` in every pass, so it
  correctly contributes `0`.

## Complexity

- **Time:** O(n²) — 4 sweeps, each O(n²) total. (Brute force is O(n³).)
- **Space:** O(n²) for `dp` + O(len(mines)) for the mine set.

## Example

`n = 5`, `mines = [[4, 2]]` → answer **2**. A plus of order 3 at `(2,2)` would need
its down arm to reach row 4, but the mine at `(4,2)` caps the downward run, so the
largest plus there is order 2.
